# ⚡ Selamat Datang di Nemesis IDE!

Nemesis IDE adalah code editor custom modern berbasis web tech (React + Monaco Editor + Node.js backend).

### Fitur yang bisa Anda coba langsung:
- **Navigasi File & Folder**: Buat file baru, folder baru, rename, dan delete melalui sidebar.
- **Monaco Editor (VS Code Engine)**: Didukung syntax highlighting, auto bracket pair colorization, line numbers, dan minimap.
- **Shortcut Cepat**: Tekan `Ctrl + S` untuk menyimpan file ke disk lokal.
- **Live Code Runner**: Klik tombol hijau **Run Code** di atas atau tombol play di terminal untuk menjalankan script `main.py` atau `index.js` secara live!
- **Terminal Terintegrasi**: Jalankan perintah shell apa saja melalui input terminal di panel bawah.
